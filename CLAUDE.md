## Agent skills

### Issue tracker

Issues live as GitHub issues on `two4teezee/Ikemen-GO-Trials-Mode`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label named after its role. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Testing handoff

Trials needs a human watching the screen. Whenever an implementation is ready to test,
produce a test checklist before calling it done. See `docs/agents/testing-handoff.md`.
